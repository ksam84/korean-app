
Korean Learning App
What this is
A personal web app for learning beginner Korean on my Android phone, saved to the home screen. Full spec: see Spec v2 below.

Rules for every session
Explain your plan and assumptions before changing code. Wait for my OK.
Make the smallest change that does the job. List the files you changed.
Keep this a static site that runs on GitHub Pages: no back end, no accounts, no API keys or secrets.
Store progress only in the phone's browser. Never store personal information.
Write Korean content in original wording. List every new Korean word so I can check it against the King Sejong Institute Korean 1A textbook.
After each change, tell me how to test it on my phone.
Commit each working change with a short, clear message.
Spec v2
Out of scope
AI conversation and any audio (until after Day 11), logins, leaderboards, other languages, multiple users, app store release, payments, graded handwriting.

Data
Lesson progress and quiz scores only, stored in my phone's browser storage. No audio, no account, no personal details. Visible only to me. Clearing the browser's site data deletes it, and Export is my backup.

Content accuracy
I check every Korean word and example against the King Sejong Institute Korean 1A textbook before it goes into the app. Nothing is copied from the textbook; the app uses its own wording.

Success measure
After 1 week, I score 80% or more on the end-of-lesson quizzes for lessons 1 to 10, without hints.

Biggest risk
Lessons run long or I skip days, guarded by the 15-minute limit. Second risk: AI-written Korean that is wrong and that I can't yet spot.

Clarifications
15-minute limit: a target for how long one lesson should take, not a timer in the app.
Day 11: there is no day-by-day lesson plan yet.
Export: shows my progress as text I can copy. There is no Import.
